## I1 — the icon seam — `done`

> One `<Icon>` component, one registry, two packs behind it. No surface
> changes yet.

- Dependencies: `@vscode/codicons` only. Its SVGs already carry
  `fill="currentColor"`, so Vite's `?raw` is the whole build story — no icon
  font, no runtime, no plugin, and only the icons the registry names reach
  the bundle. **Phosphor was not installed**: nothing in the current
  inventory needed it, and an unused dependency is a liability. The rule
  stands and lives in the registry's header — when a concept has no Codicon,
  add `phosphor-svelte`, put the entry there, and name the gap beside it.
- New `src/renderer/src/components/Icon.svelte` + `src/renderer/src/lib/icons.ts`
  — a registry mapping semantic names (`chevron-right`, `branch`, `close`,
  `open-external`, `image`, `check`, `error`…) to a pack and glyph. The
  Codicons-before-Phosphor rule is enforced here: a Phosphor entry carries a
  comment naming the Codicon gap.
- Size and baseline: **1em by default**, so an icon is the size of the text
  it sits in and a 10px chrome label gets a smaller mark than a 12px row
  without either being told. A `-0.12em` optical nudge sits the SVG box where
  a glyph's mass sits; measured in the browser at 0.44px from the parent's
  optical centre.
- The registry documents the unicode that stays as text (`·`, `…`, and
  whether `↗` survives).
- Acceptance: every registry entry resolves and draws; bundle-size delta
  **+19KB** (1,180KB → 1,199KB renderer chunk).
- Validation: registry unit test (every name resolves); browser screenshots
  at 1x and 2x.
