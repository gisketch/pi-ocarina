## I1 — the icon seam — `todo`

> One `<Icon>` component, one registry, two packs behind it. No surface
> changes yet.

- Dependencies: `@vscode/codicons` (SVGs) and `phosphor-svelte`; both
  render inline SVG, `currentColor`, no fonts, no network.
- New `src/renderer/src/components/Icon.svelte` + `src/renderer/src/lib/icons.ts`
  — a registry mapping semantic names (`chevron-right`, `branch`, `close`,
  `open-external`, `image`, `check`, `error`…) to a pack and glyph. The
  Codicons-before-Phosphor rule is enforced here: a Phosphor entry carries a
  comment naming the Codicon gap.
- Size and baseline: measured against the mono grid in the browser (the
  spec's open question) — the chosen size and alignment recipe recorded here
  and in the component.
- The registry documents the unicode that stays as text (`·`, `…`, and
  whether `↗` survives).
- Acceptance: a test page (or mock thread) draws every registry entry at row
  height, aligned, in both themes; bundle-size delta measured and recorded.
- Validation: registry unit test (every name resolves); browser screenshots
  at 1x and 2x.
